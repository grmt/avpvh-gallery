# WordPress stubs

Vendored locally (rather than pulled in as a Composer dependency) from the
`skaut/wordpress-stubs` project (https://github.com/skaut/wordpress-stubs),
with local additions/corrections for gaps used by this plugin (REST API
stubs, a proper `WP_Error` constructor, wpdb output-format constants,
`is_wp_error()` type-narrowing). See `LICENSE` for the original MIT
copyright notice, preserved as required by that license.
